GUI style customization

Built-in themes

Starting from version 4.16, QLC+ 4 ships with a new application shell, a modern icon set based on the original QLC+ iconography, the Inter typeface and four selectable themes. Click the Appearance button in the top command bar (the palette icon) to change them at runtime:

  • Midnight: the default. Layered near-black surfaces, subdued borders and the QLC+ blue accent. Designed for long operating sessions and dark stages.
  • Daylight: a clean light theme with the same shell, spacing and accent system.
  • OLED: true black backgrounds for OLED panels and very dark environments.
  • Classic: restores the stock Qt/platform widget look used before version 4.16. The new navigation shell remains, without motion.

The top command bar keeps file, monitor, live edit, panic, blackout and the Design/Operate switch within reach, while a navigation rail replaces the old bottom tab strip. The navigation can be placed on the left as a sidebar or along the bottom edge. Choose Navigation → Sidebar or Navigation → Bottom bar from the Appearance menu, or use the Navigation section in Appearance settings.... The choice is saved in the workspace and restored on the next start; the active indicator, hover animation and page transitions are kept in both positions. Opening the command palette with Ctrl+Shift+P or the search button gives keyboard access to every action.

Icons are based on the original QLC+ iconography and restyled as clean flat shapes. Their original colour identity is preserved, so fixtures, lamp types, functions, shows, the Virtual Console, Inputs/Outputs, the address tool, DMX dump, fixtures monitor and blackout remain easy to recognise. Generic actions stay monochrome. Neutral outlines and the surrounding pill follow hover, selection and disabled state plus the selected theme, while the coloured parts of the legacy icons keep their identity. The original QLC+ logo is kept in the header.

The OLED theme uses pure black for the main window, command bar, navigation rail and page surfaces, so large areas of the screen are actually off on OLED panels. Raised elements such as menus and dialogs remain slightly lighter for depth and readability.

The Appearance settings... dialog groups the four themes, the accent color presets and custom picker, the navigation position, the Animated effects toggle for hover fades, ripples, page transitions and navigation motion, and the custom stylesheet shortcuts. All choices are stored in the QLC+ settings and restored on the next start.

User stylesheet overrides

Starting from version 4.5.0, QLC+ can also read a user custom file to change the GUI appearance in a very accessible way. The user stylesheet is applied on top of the selected built-in theme, so it can override individual components.
If no file is found, QLC+ will start with the selected built-in theme.

The GUI style file

The file name is hardcoded into QLC+ and must be: qlcplusStyle.qss
The style file must also be placed in a specific path which is:

  • Linux: $HOME/.qlcplus
  • Windows: Your user folder/QLC+
  • OSX: Library/Application Support/QLC+
The Appearance menu provides Open custom stylesheet folder and Reload custom stylesheet entries to edit and apply the file without restarting QLC+. The MAIN section is reloaded immediately; component specific sections (for example the Virtual Console or Simple Desk sections) are applied when their widgets are created, so restart QLC+ to refresh those.

The style file must have a CSS syntax. If you're comfortable with web designing, you should find the creation of this file very easy!
Since the style file is strictly related to the inner Qt objects, you might want to read the following articles to find out the elements' names and the additional CSS properties the Qt team added to the default CSS syntax.

It is up to your imagination how you prefer to customize the QLC+ GUI appearance! If you find a style worth sharing, don't forget to send in your contribution by posting it online in the QLC+ forum

QLC+ dark blue style example

Just to give you an example of how easy this process is, here's a blue-ish dark style for QLC+.
If you copy the following lines into qlcplusStyle.qss in the right location as explained above, you will see it immediately applied to QLC+.

QMainWindow, QDialog
{
 background-color: #404B57;
 color: #E6E6E6;
}

QTreeWidget
{
 background-color: #3A444F;
 alternate-background-color: #404B57;
 color: #E6E6E6;
}

QTextBrowser
{
 background-color: #3A444F;
 color: #E6E6E6;
}
